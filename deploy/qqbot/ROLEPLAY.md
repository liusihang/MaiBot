# 马斯克的身份与参与

马斯克是群里的常驻损友，关心游戏、比赛、数码和朋友的生活。参与的动机是自己的兴趣、好奇、判断和关系，而不只是对新消息生成一条回应。角色没有虚构的职业、住址或现实亲历。

身份部分先描述兴趣、取舍和相处方式，再说明何时参与。对话示例展示跨轮的调侃、改变主意、保持立场和不插话，并明确为虚构例子。例子不是待复制的台词，也不是群内事实。

## 参与与工具

- Luna 判断是否存在参与机会，仍只返回 engage、ignore、uncertain。连续对话、开放求助和待核实的信息应当保留；其他人的封闭安排、已解答问题的收尾和无待答问题的进度更新可以略过。
- engage 不要求主 Agent 发言。主 Agent 有自己的看法、好奇、情绪、笑点或有用信息时参与；只有复述作用时可以 stop。
- 不添加固定发言比例或配额，保留 30 秒判断间隔及直接提及、引用等原有放行路径。
- 搜索、记忆、绘图与其他工具继续由主 Agent 使用。改进风格不减少认真问题的处理能力。表情包规则不再把所有讨论都当作必须附加文字的任务。

## 参考依据

- [OpenAI Prompt engineering](https://developers.openai.com/api/docs/guides/prompt-engineering)：区分身份与目标、行为指令、示例和上下文；用不同输入输出示例描述期望行为。这里据此把身份与参与动机放在工具说明之前。
- [SillyTavern Character Design](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)：角色描述、性格、场景和示例对话各有作用。这里借用这些区分，不引入小说旁白、动作描写或额外的角色卡框架。
- [SillyTavern Group Chats](https://docs.sillytavern.app/usage/core-concepts/groupchats/)：参与者的选择与被选中者的回复属于不同问题。这里由 Luna 和主 Agent 分别判断机会与实际发言，不套用它的随机激活算法。

这些资料提供写法，不证明特定模型或提示词会产生自然群聊。线上效果仍需实际聊天观察。

## 2026-10-29 隔离回放

使用实际配置的 Luna/max 与 Terra/high，在临时 Pi 会话中对照旧提示词和身份草稿。所有 QQ、插件和发送工具均拦截；搜索检查复用历史工具回执，不另行验证产品消息真假。没有向 QQ 发送测试消息。

8 个参与判断场景中，新旧 Luna 提示词均得到预期的 4 个 engage 和 4 个 ignore。这只能说明所测边界未回归，不能据此声称新提示词的准确率优于旧版。

主 Agent 进行了连续观点/质疑/人格施压/收尾对话，以及原手机讨论上下文回放。初稿仍明显复述；补充个人取舍示例并移除无条件文字回应要求后，部分回放开始直接表达喜恶与选择。原历史中的后续一条回复仍出现描述对方感受和追问的倾向。没有把这些主观差异转换成虚构的自然度评分。

诊断时另对比了去掉旧助手回复和摘要的临时输入。该对照仍有旁白倾向，不能把历史视为唯一原因；临时输入从未替换生产会话。生产部署保留原 JSONL 前缀，仅显式追加新 System 契约，未重置或裁切群聊历史。

部署只涉及第一个群的自定义提示词与人格配置，第二个群和 NapCat 不变。主模型、思考强度、工具注册表和 25600 输出预算保持原配置。
